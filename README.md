# Number Guessing Game

## What it does
A fun number guessing game written in C language.
The computer picks a random number between 1 and 100.
You have to guess it — the program tells you if you're too high or too low!

## How to run it
1. Make sure GCC compiler is installed
2. Open terminal and compile:

gcc guessing_game.c -o guessing_game

3. Run the game:

./guessing_game

4. Start guessing!

## Tech used
- C Language
- GCC Compiler
